## Featured Work

### Multi-Horizon Equity Forecasting: News Sentiment vs. Inter-Stock Graph Structure
*MSc dissertation, University of Huddersfield (2026). Code repository coming soon.*

A controlled comparison of two common claims in financial forecasting: that news sentiment adds
predictive signal, and that modelling stocks as a connected graph outperforms treating them
independently.

- Built two pipelines, FinBERT sentiment features feeding an LSTM and a Graph Attention Network over
  an inter-stock relationship graph, evaluated across multiple forecast horizons against a matched baseline
- Applied Diebold–Mariano tests to distinguish genuine improvement from noise
- Validated on held-out, previously unseen tickers, with ablation and sensitivity analysis
- Explained model behaviour using SHAP, Integrated Gradients and attention-weight analysis
- Delivered an interactive demonstrator application for exploring predictions and their drivers

**Stack:** Python, PyTorch, Hugging Face Transformers, FinBERT, pandas, scikit-learn, SHAP
